# pkgtools

![pkgtools hex sticker](inst/hexsticker/hex-sticker.png)

pkgtools hex sticker

A set of tools to help develop R packages and to maintain non-package
analysis code in package like formats.

`pkgtools` stable releases from `r-universe` by:

``` r
# Enable repository from terminological
options(repos = c(
  terminological = 'https://terminological.r-universe.dev',
  CRAN = 'https://cloud.r-project.org'))

install.packages('pkgtools')
```
